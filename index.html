PorchLight

Third place at the Cline, Parallel & Composio Hackathon, San Francisco, October 19, 2026

See PorchLight on GitHub

Problem
People see a neighborhood problem, like a broken streetlight or a pothole, and don't know which city agency fixes it. You drop a pin, and PorchLight finds which San Francisco agency fixes it, with a link to the source.
What I did
At the one-day hackathon, I directed three AI coding agents to build it: Cline, Cursor and Claude Code.
What agents and Seth did
The agents built all of it. Cline wrote the core that finds the right agency for a pin, Cursor set up the project, and Claude Code made most of the other changes. Seth built none of it.
How it was checked
Automated tests of the main steps, a live run on Composio's real service, and demo pins checked against SF.gov sources.
Result
Third place at the hackathon. The code is public.

RISE

A reading app in open beta that I work on with Seth Carlson

Try RISE in your browser

Problem
Let a book be read as a timed stream, with images, sound and moving visuals, not only as a typeset page.
What I did
I owned its Composer feature, which lets ChatGPT write a reading for RISE to play. I made the product calls, directed the AI agents that built it, and tested it by hand. In a live ChatGPT session I reported what worked and what didn't, for example that the model couldn't see an on-screen marker.
What agents and Seth did
AI agents, mostly Claude, wrote most of the code. Seth Carlson built the engineering infrastructure and, with agents, large parts of the core and interface.
How it was checked
Automated tests, including browser tests and real video encoding, run in its GitHub workflows.
Result
Live in open beta. No usage numbers yet.

How I work with AI

I decide what gets built, direct the AI agents that build it, and check their work.

I don't write code by hand; the agents do. Each project above names which ones.

  1. Specify

    I decide what to build and give each agent a clear task.

  2. Direct

    Directing AI agents is a lot like coordinating people: each one needs a clear role, a shared goal, enough context and a clean handoff. I use Claude Code, Cursor, Cline and Codex.

  3. Check

    I don't take an agent's word that the tests pass. In the agent system my team uses, a change is accepted only if our own automated checks pass.
